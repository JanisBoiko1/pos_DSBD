# Pós-Graduação em Data Science & Big Data (DSBD) - Portfólio de Projetos

Bem-vindo ao meu repositório de estudos e exercícios práticos desenvolvidos ao longo da minha especialização em **Data Science e Big Data**. Este espaço reúne implementações que transitam desde os fundamentos matemáticos e estatísticos até a aplicação de algoritmos avançados em R e Python.

O objetivo deste portfólio é demonstrar minhas habilidades técnicas na resolução de problemas reais e exercícios desafiadores, solidificando a base teórica necessária para atuar como Cientista de Dados.

## Estrutura do Repositório

*   **`R/`**: Contém listas de exercícios e projetos exploratórios utilizando a linguagem R. Foco em análise exploratória de dados, visualização (ggplot2) e aplicações de inferência estatística. (Projetos RMarkdown inclusos).
*   **`python/`**: Diretório dedicado a scripts Python e notebooks. Inclui exercícios que abordam lógica de programação, manipulação de dados (Pandas) e aplicações práticas de aprendizado de máquina e métodos numéricos.
*   **`computacao_paralela/`**: Projetos focados em otimização de desempenho e processamento paralelo, fundamentais para o tratamento de Big Data.
*   **`inferência estatística/`**: Módulo central focado em Estatística, Probabilidade, Cálculo Diferencial/Integral e Álgebra Linear. Aqui estão as implementações dos métodos que sustentam os algoritmos de Machine Learning.

## Tecnologias e Habilidades Aplicadas

*   **Linguagens:** Python, R.
*   **Ambientes & Ferramentas:** RStudio, Jupyter Notebooks, Git.
*   **Fundamentos Matemáticos:** Álgebra Linear (autovalores, decomposição LU, determinantes, gradiente descendente), Cálculo (integrais, derivadas) e Métodos Numéricos (método de Newton, Gauss-Seidel, Gauss-Jordan).
*   **Estatística e Probabilidade:** Inferência estatística, distribuições de probabilidade e testes de hipóteses.
*   **Manipulação de Dados:** Análise de datasets reais (ex: `trainTitanic.csv`).

## Destaques dos Projetos

*   **Implementações Matemáticas "From Scratch":** Desenvolvimento de funções próprias para cálculo de decomposição de matrizes, sistemas lineares e métodos de otimização (gradiente descendente), demonstrando compreensão profunda do funcionamento interno de algoritmos.
*   **Análises Estatísticas:** Aplicação de conceitos de inferência e probabilidade em listas de exercícios práticos, unindo teoria à prática com R.

## Como utilizar este repositório

Sinta-se à vontade para navegar pelas pastas de seu interesse. Para executar os scripts localmente, certifique-se de ter as respectivas linguagens e bibliotecas instaladas:

*   **Para R:** Abra os arquivos `.Rproj` ou `.Rmd` (RMarkdown) no RStudio.
*   **Para Python:** Execute os scripts `.py` em seu terminal ou IDE preferida (VSCode, PyCharm) com as bibliotecas `numpy`, `pandas`, `matplotlib`, etc., devidamente instaladas.
